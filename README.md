# Лабораторная работа №1 по АКОС (Linux)

Скрипты для мониторинга заполненности папки, архивации и удаления старых файлов при превышении заданного порога.

Особенности реализации:
- Shell-скрипты: `src/cleanup.sh` и `tests/test_runner.sh`.
- Поддержка сжатия LZMA при установленной переменной `LAB1_MAX_COMPRESSION=1` (на 9 баллов).
- Автоматические тесты работают полностью в user-space без root-прав и монтирования.
- Во всех тест-кейсах папка логов весит от 0.5 GB (от 600 до 900 MB).

---

## Как решены задачи и что использовалось

### 1. Проверка заполнения папки в процентах
- **Как решили**: Скрипт поддерживает как работу с реальной файловой системой через `df`, так и передачу квоты в аргументах или через переменную окружения `LOG_MAX_SIZE_MB` (для тестирования в обычном каталоге без root).
- **Главные инструменты**: `du -sk` (занятый объем в КБ), `df -k` (размер диска/раздела), вычисление `$((CURRENT_KB * 100 / TOTAL_KB))`.

### 2. Проверка порога и расчет дельты
- **Как решили**: Проверяем условие `PERCENT <= THRESHOLD`. Если порог превышен, вычисляется дельта - точный объем в КБ, который необходимо освободить.
- **Главные инструменты**: Условие `[ "$PERCENT" -le "$THRESHOLD" ]`, расчет дельты `$((CURRENT_KB - TARGET_KB))`.

### 3. Фильтрация и отбор N старейших файлов
- **Как решили**: Сортируем список файлов по дате изменения (от старых к новым). По очереди берем файлы, пока их суммарный вес не покроет нужную дельту.
- **Главные инструменты**: `ls -tr`, построчное чтение `while read`, проверка `[ -f ]`, замер размера через `du -k`.

### 4. Архивация и удаление файлов
- **Как решили**: Пакуем отобранные файлы в архив с временной меткой. При успехе архивации удаляем их из папки логов.
- **Главные инструменты**: `tar -czf` (сжатие gzip по умолчанию), ключ `-C`, дата `date +%Y%m%d_%H%M%S`, удаление `rm -f`.

### 5. Режим максимального сжатия LZMA (на 9 баллов)
- **Как решили**: При `LAB1_MAX_COMPRESSION=1` создается архив с расширением `.tar.lzma` через ключ `--lzma`.
- **Главные инструменты**: Проверка `[ "${LAB1_MAX_COMPRESSION:-0}" = "1" ]`, флаг `tar --lzma -cf`.

### 6. Автоматические тесты в user-space
- **Как решили**: Скрипт создает изолированное окружение `test_env`, проверяет 5 сценариев и очищает за собой через `trap`.
- **Главные инструменты**: `fallocate -l` / `truncate -s`, `touch -d` (установка точного mtime), `tar -tf` / `tar -tzf`, `trap ... EXIT`.

## Использование

### Запуск очистки:
```bash
./src/cleanup.sh [путь_к_логам] [порог_%] [путь_к_бэкапам] [квота_МБ]
```

Примеры:
```bash
# Очистка папки ./log при превышении 70%, бэкапы в ./backup (размер диска из df)
./src/cleanup.sh ./log 70 ./backup

# С квотой 1000 MB (удобно для user-space)
./src/cleanup.sh ./log 70 ./backup 1000

# Сжатие LZMA (на 9 баллов)
LAB1_MAX_COMPRESSION=1 ./src/cleanup.sh ./log 70 ./backup 1000
```

### Запуск тестов:
```bash
chmod +x src/cleanup.sh tests/test_runner.sh
./tests/test_runner.sh
```
